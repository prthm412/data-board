Project Instructions

The project is about building a simple data Application - where a user is able to upload a dataset, view the list of uploaded datasets. Select a dataset and create visualizations to analyze the data.

This is a small but representative sample of the kind of work you will be doing at xVectorlabs albeit at scale and complexity.

We encourage you to work on the project to get a better understanding of your interests and alignment with the kind of work you will be doing at xVector.

If you are proficient in python and javascript this project should take 3 hours of your time. We understand finding a free slot for a block of time is hard. Hence we don't have a time limit setup.
Please use the coderbyte platform to submit your project.

Detailed Specification Document: ProjectSpec.md

 How to Submit & Requirements:

1. Submission Options: You may either:

   a)Use the Git integration available within the Coderbyte platform to publish your project, OR

   b)Develop the project in your own GitHub
   repository and submit that repository.
2. After completing the project, you must do the following:

   a)Include the public GitHub repository link in your Coderbyte submission.

   b)Email the same repository link to us as specified in the assessment instructions.

   c)Please ensure the repository is publicly accessible before submitting.
3. Repository Deliverables Checklist:
   Ensure your repository contains:

   a)Full-stack source code

   b)A sample CSV file for trying out the app

   c)A README with clear setup and run instructions, steps for running tests, notes on your JWT refresh strategy, and any technical assumptions made.
